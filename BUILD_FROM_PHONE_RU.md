# Сборка APK с телефона через GitHub Actions

Этот проект содержит workflow `.github/workflows/build-apk.yml`, который собирает debug APK в облаке GitHub. Сам APK в архив не включён.

## Порядок действий

1. В браузере телефона откройте https://github.com и войдите в аккаунт.
2. Создайте новый репозиторий (можно Private), например `chess-mentor`.
3. Нажмите **Add file → Upload files**.
4. Распакуйте ZIP проекта на телефоне. Загрузите содержимое папки `ChessMentorAndroid-final` в корень репозитория. Важно: вместе с остальными файлами должна загрузиться скрытая папка `.github/workflows` и файл `build-apk.yml` внутри неё. Если мобильный интерфейс не показывает скрытую папку, используйте GitHub в режиме «Версия для ПК» или загрузите проект через Git-клиент, который поддерживает скрытые файлы.
5. Нажмите **Commit changes**.
6. Откройте вкладку **Actions** репозитория и выберите запуск `Build Chess Mentor APK`. Если workflow не запустился автоматически, нажмите **Run workflow**.
7. Дождитесь зелёного статуса завершения. Откройте выполненный запуск, прокрутите до **Artifacts** и скачайте `ChessMentor-debug-apk`.
8. Распакуйте скачанный архив. Внутри будет `app-debug.apk`. Откройте его на телефоне и разрешите установку из этого источника, если Android запросит разрешение.

## Важно

- Это debug APK для тестирования, не релизная подписанная сборка.
- Успешная компиляция не подтверждает корректность распознавания доски, работы Stockfish или качества подсказок.
- В текущем проекте наличие и подключение рабочего бинарника Stockfish и модели распознавания нужно проверить отдельно. Не считать их готовыми только потому, что APK собрался.
- Не загружайте в публичный репозиторий личные ключи, пароли или другие секреты.
